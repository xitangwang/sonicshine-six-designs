Protect the part at every handoff

Identify surfaces that must not be clamped or marked. Photograph the current fixture and note which moves are manual, which require a lift, and where a basket needs to pause for drainage.

What to put in the brief

Contact surfaces
Show fragile edges, finished faces, threaded features and areas where a support can safely bear.
Handling load
Total mass including the basket, loading height and operator access.
Cycle boundaries
Define the start and end of a cycle so setup time is included consistently.
Plant interface
Send a marked-up layout with clearances, access routes and upstream/downstream handoffs.
Configuration guidance only. The final specification depends on the workpiece, trial criteria and site review.
