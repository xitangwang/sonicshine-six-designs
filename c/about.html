Service / project pathway

Five steps to a useful proposal.

Use this review path to keep the sample, trial record and quotation connected.

  1. Define the workpiece

    Share a drawing or photographs, the material and finish, the residue and the next production step.

  2. Agree the trial criteria

    Define the reference sample, inspection method and how each result will be recorded. Confirm safe sample-handling instructions before shipping.

  3. Review a representative trial

    Use agreed conditions, a repeatable basket arrangement and recorded observations. Check both cleaning and possible surface change.

  4. Review the proposed system

    Discuss the process sequence, handling, floor space, utilities and the assumptions that a quotation should contain.

  5. Plan handover and support

    Agree documentation, operator instruction, maintenance access and service scope for the specific project.
