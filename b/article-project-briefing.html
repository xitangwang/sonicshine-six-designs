How to brief Sonic Shine on a custom project.

Send useful first details even when no final specification exists.Factory Journal · design edition editorial

Send useful first details even when no final specification exists.

Start with an unprepared part

A representative workpiece is more useful than a freshly polished example. Record what it looks like as it arrives from your normal process: include a scale reference, the material and finish, and the places where residue is hardest to remove.

Describe the next operation

Assembly, coating and inspection can require different acceptance checks. Explain where the part goes after cleaning and who decides whether it can move on. A simple photograph may be enough to start the conversation, even if formal acceptance criteria are not yet fixed.

Add the production constraints

A project brief should identify batch weight and dimensions, expected loading method, available floor space and any existing handling equipment. Separate fixed constraints from details that can be explored in a trial.

Send what you know

Use the project sheet to record these facts. Missing information can be resolved in a project discussion; avoid converting an early estimate into a guaranteed performance target.
